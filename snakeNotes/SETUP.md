# Setup NotesSnake — tanpa git

## Cara 1: dari GitHub (HP/laptop apa pun)

1. Buka repo **Ba.speech** di github.com.
2. Klik tombol hijau **Code** → **Download ZIP**.
3. Ekstrak ZIP → buka folder `notes-snake`.
4. Klik 2x `index.html` → jadi di browser. Selesai.

## Cara 2: file langsung

Unduh 2 file ini dari repo (klik file → Download): `notes-snake/index.html`, `notes-snake/logo.svg`. Taruh sejajar dalam satu folder → buka `index.html`.

## Catatan

- Data catatan tersimpan di browser masing-masing (localStorage).
- Tidak perlu install, tidak perlu API key.
